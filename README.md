# DF-Iris

This repository provides a PyTorch implementation of DF-Iris for presenting the core method pipeline described in the paper, including the PDC backbone, global feature branch, local discriminative texture discovery, feature fusion, progressive training, basic verification evaluation, and visualization analysis.

DF-Iris is designed for near-eye iris recognition. The model uses pixel-difference convolution to enhance fine-grained iris texture modeling, and combines global representation learning with local discriminative texture discovery so that the network can focus on identity-relevant iris regions in an end-to-end manner.

## Code Structure

```text
df_iris/
├── model.py       # Main DF-Iris model
├── dataset.py     # Data loading and split construction
├── train.py       # Training entry
├── test.py        # Feature extraction and verification evaluation
├── metrics.py     # EER and verification accuracy
├── visualize.py   # Visualization analysis
└── utils.py

configs/           # Dataset and training configurations
visualization/     # Example visualization results
tests/             # Basic functional tests
```

The main model is implemented in `df_iris/model.py`, including the PDC backbone, global branch, local texture branch, CAM/CDM-based texture discovery, token aggregation, and feature fusion modules.

## Data Format

The code supports a subject-and-eye based data structure:

```text
data_root/
├── subject_001/
│   ├── L/
│   │   ├── image_001.png
│   │   └── image_002.png
│   └── R/
│       ├── image_001.png
│       └── image_002.png
├── subject_002/
│   ├── L/
│   └── R/
└── ...
```

It also supports a manifest file for specifying image paths and data splits:

```csv
image_path,subject,eye,identity,split
/path/to/image_001.png,001,L,001_L,train
/path/to/image_002.png,001,L,001_L,val
/path/to/image_003.png,002,R,002_R,test
```

## Training

Modify the configuration file in `configs/` by setting the dataset path and output directory:

```yaml
data:
  data_root: "/path/to/dataset"

output:
  output_dir: "outputs/casia_lamp"
```

Start training with:

```bash
python -m df_iris.train --config configs/casia_lamp.yaml
```

The training process follows a progressive strategy:

```text
global -> local -> integrated -> full
```

The output directory stores model checkpoints, training logs, extracted test features, and basic verification results.

## Feature Extraction and Evaluation

Extract features from images:

```bash
python -m df_iris.test infer \
  --checkpoint outputs/casia_lamp/best.pt \
  --input /path/to/images \
  --output outputs/casia_lamp/features_infer.npz
```

Evaluate saved features under a basic verification setting:

```bash
python -m df_iris.test eval-features \
  --features outputs/casia_lamp/features_test.npz \
  --output outputs/casia_lamp/eval_metrics.json
```

The evaluation output includes EER, verification accuracy, threshold, genuine pairs, and impostor pairs.

## Visualization

The `visualization/` folder provides example visualization results generated by the model. These results illustrate how DF-Iris discovers discriminative iris texture regions from near-eye images. The visualization corresponds to the analysis of global response, class-related activation, class-difference response, and local texture response.

The folder contains the following visualization items:

```text
Input Eye Image.png          # Input near-eye image
Global Spatial Prior.png     # Spatial response generated by the global branch
Target-Identity CAM.png      # Class activation map for the target identity
Class-Difference Map.png     # Class-difference response highlighting identity-discriminative regions
Selected Texture Patches.png # Discriminative texture patches selected by the local branch
Local Texture Response.png   # Local texture response formed by the local branch
```

These results show how the model moves from the overall iris region to more identity-discriminative local texture regions. The global spatial prior reflects the model's coarse attention to the iris structure. The Target-Identity CAM indicates regions related to the target identity. The Class-Difference Map further highlights areas that are more useful for distinguishing different identities. The Selected Texture Patches and Local Texture Response show how the local branch selects and aggregates local discriminative textures.

Run the visualization script with:

```bash
python -m df_iris.visualize \
  --checkpoint outputs/casia_lamp/best.pt \
  --input /path/to/images \
  --output-dir outputs/casia_lamp/visualization
```
